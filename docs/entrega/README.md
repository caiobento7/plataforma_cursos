# Entrega final: CursoLab

Materiais da entrega da disciplina Princípios de Engenharia de Software (UERJ/IPRJ).

| Arquivo | Conteúdo |
|---|---|
| `CursoLab-apresentacao.pptx` | Slides da apresentação (25), no template da disciplina, com notas do apresentador |
| `CursoLab-apresentacao.pdf` | Os mesmos slides em PDF, para apresentar pelo navegador |
| `roteiro-de-fala.md` | Texto de cada slide para ensaiar a apresentação |
| `CursoLab-relatorio.pdf` | Relatório final (21 capítulos, 26 figuras, 12 tabelas) |
| `diagramas/` | Diagramas em Mermaid (`.mmd`) e as imagens geradas (`.png`) |
| `prints/` | Capturas das telas da versão publicada |
| `fontes/` | Texto do relatório (`relatorio-parte1.md`, `relatorio-parte2.md`) e conteúdo dos slides (`slides.mjs`) |
| `assets/` | Logo da UERJ e do Instituto Politécnico |

As capturas foram feitas com uma aluna e um administrador temporários (`@cursolab.test`),
removidos ao final, e os números citados (158 verificações, 8 suítes, 36 rotas, 10 tabelas,
12 Pull Requests) foram conferidos no código.
